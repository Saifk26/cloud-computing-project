## What I learned

1. **Cloud basics:** cloud computing models (IaaS, PaaS and SaaS).
2. **Core cloud services:** compute, storage, networking and databases.
3. **Virtualization and scalability:** how cloud infrastructure supports high availability and elasticity.
4. **Security and identity:** basics of IAM, encryption and compliance principles.
5. **Hands-on labs:**
   - Launching virtual machines
   - Creating and managing storage buckets
   - Setting up basic cloud networks
   - Deploying simple applications in the cloud
6. **Cost management:** cloud billing, usage tracking and resource optimization.

This internship gave me a solid foundation in cloud computing and prepared me for further certifications such as AWS Cloud Practitioner.
